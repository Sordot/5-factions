## 1. CRITICAL — Fix Main Menu Horizontal & Vertical Screen Cutoff (`1280×720`)

### Root Cause
- `project.godot` uses a `1280×720` base viewport (`stretch/mode="canvas_items"`, `stretch/aspect="expand"`).
- `scenes/ui/main_menu.tscn` has `RootMargin` (`24 px` left/right → `1232 px` usable width) and `BodyHBox` (`14 px` separation).
- In `FactionColumn/LockedGrid` (`columns = 2`), `LockedSlot2`–`LockedSlot5` contain long single-line subtitles (`"Stealth & Algorithmic Subversion  •  LOCKED — IN DEVELOPMENT"`) with no wrapping or clipping, forcing `FactionColumn` to ~`780–790 px` minimum width.
- In 2.8, `scripts/ui/main_menu.gd` (`_build_slot_roster_widgets()`, L265–283) inserted `fac_opt` (`custom_minimum_size = Vector2(78, 24)`) into each row of `SlotRosterVBox` alongside `pip (7)`, `slot_lbl (22)`, `ctrl_btn (54)`, `ally_opt (52)`, `diff_opt (78)`, `style_opt (78)`, `separation = 4`, and `OptionButton` internal arrow/theme padding—forcing `ConfigPanel` past its `424 px` target to ~`495–515 px`.
- Combined width (`~790 + 14 + ~505 = ~1309 px`) exceeds `1232 px`, pushing the right edge of `ConfigPanel` off the screen.

### Required Changes
1. **`scenes/ui/main_menu.tscn`:**
   - On `LockedSlot2`, `LockedSlot3`, `LockedSlot4`, and `LockedSlot5`, set `autowrap_mode = 3` (Word Smart) and `clip_text = true`, and add `theme_override_font_sizes/font_size = 11` so `FactionColumn` can flex cleanly down to `680–720 px` without blowing out `BodyHBox`.
   - Set `ConfigPanel` `custom_minimum_size = Vector2(448, 0)` and `size_flags_horizontal = 0` (Shrink/Fixed) while keeping `FactionColumn` at `size_flags_horizontal = 3` (Expand Fill).
   - Update `SubtitleLabel` text from `"MILESTONE 2.5 SKIRMISH EXPANSION  •  BUILD 0.2.5"` to `"TECHNOZEN REAL-TIME STRATEGY  •  MILESTONE 2.8 ENGINE HARDENING  •  BUILD 0.2.8"`.
2. **`scripts/ui/main_menu.gd` (`_build_slot_roster_widgets()`):**
   - Set `row.add_theme_constant_override("separation", 3)`.
   - On `ally_opt`, `fac_opt`, `diff_opt`, and `style_opt`, set:
     - `clip_text = true`
     - `fit_to_longest_item = false`
   - Tighten minimum widths so all 7 row widgets fit inside `424 px` inner width with breathing room:
     - `pip`: `Vector2(6.0, 22.0)`
     - `slot_lbl`: `Vector2(20.0, 0.0)`
     - `ctrl_btn`: `Vector2(48.0, 24.0)`
     - `ally_opt`: `Vector2(46.0, 24.0)`
     - `fac_opt`: `Vector2(66.0, 24.0)`
     - `diff_opt`: `Vector2(68.0, 24.0)` (`SIZE_EXPAND_FILL`)
     - `style_opt`: `Vector2(66.0, 24.0)` (`SIZE_EXPAND_FILL`)
   - Verify total row min width: `6 + 20 + 48 + 46 + 66 + 68 + 66 + (6 * 3) = 338 px` (easily fits inside `ConfigPanel` even with panel padding).
   - Fix L497 in `_wire_locked_card()` so the notice references the currently active faction's `short_code` / `display_name` instead of hardcoding `"GENESIS_V2"`.

## 2. HIGH — In-Game HUD & Tech Tree Viewport Edge Safety (`1280×720`)

### Issues Found
1. **Spectator Bar & Resource Bar Collision (`ui/hud/resource_hud.tscn`):**
   - `TopLeftSpectatorAnchor` uses `offset_right = 620.0` while `TopRightAnchor` uses `offset_left = -740.0`. At `1280 px` width, `620 + 740 = 1360 px`, causing the two top bars to overlap in AI-vs-AI Spectator Mode.
2. **Tech Tree Vertical Overflow (`scenes/ui/tech_tree_overlay.tscn` & `scripts/ui/tech_tree_overlay.gd`):**
   - `ModalPanel` has a fixed `custom_minimum_size = Vector2(1060, 560)` with no `ScrollContainer`. Once `FactionTabsRow` is shown (2+ playable factions) or a tier contains 4–5 buildings (e.g., Tier 0 + `Defense Turret`), cards can push `ModalPanel` past `720 px` and clip at the top/bottom edges.

### Required Changes
1. **`ui/hud/resource_hud.tscn`:**
   - Reduce `TopLeftSpectatorAnchor` `offset_right` to `520.0` and `TopRightAnchor` `offset_left` to `-680.0` (with compact font/padding if needed) so `520 + 680 = 1200 px < 1280 px` with an `80 px` safety gap at `1280×720`.
2. **`scenes/ui/tech_tree_overlay.tscn` & `scripts/ui/tech_tree_overlay.gd`:**
   - Wrap `ColumnsRow` inside a `ScrollContainer` (`horizontal_scroll_mode = SCROLL_MODE_DISABLED`, `vertical_scroll_mode = SCROLL_MODE_AUTO`, `size_flags_vertical = SIZE_EXPAND_FILL`) so tall tier columns scroll cleanly inside the modal without ever pushing `ModalPanel` off-screen.
   - Change `ModalPanel` `custom_minimum_size` to `Vector2(1040, 520)` and ensure `RootControl` margins keep it within `1280×720`.

## 4. MEDIUM — Fix Asymmetric `extra_starting_units` Spawning in `MatchManager`

### Root Cause
- In `scripts/systems/match_manager.gd` (`_bootstrap_skirmish_teams()`, L249–261), when a team's `FactionData.starting_hub_scene` matches the map's pre-placed hub (`nexus_vat.tscn`), `hub_matches` evaluates to `true` and `_swap_team_starting_loadout()` is skipped.
- Meanwhile, `resources/factions/genesis_v2_faction.tres` defines `extra_starting_units = [clone_trooper.tscn, clone_trooper.tscn, stinger.tscn]`.
- Result: `GENESIS_V2` never receives its `extra_starting_units` on pre-placed skirmish maps, while any future Faction #2 (whose hub won't match `nexus_vat.tscn`) *will* run `_swap_team_starting_loadout()` and receive its `extra_starting_units`—creating an unfair starting-army asymmetry.

### Required Changes
1. **`resources/factions/genesis_v2_faction.tres`:**
   - Clear `extra_starting_units = Array[PackedScene]([])` if standard skirmish openings are intended to be **1 Hub + 3 Workers** (matching the pre-placed maps), **OR** keep it populated only if every faction is intended to start with a combat escort.
2. **`scripts/systems/match_manager.gd` (`_bootstrap_skirmish_teams()`):**
   - If `hub_matches == true` and `not fac.extra_starting_units.is_empty()`, check whether the team already has combat units on the map; if not, spawn `fac.extra_starting_units` using the exact same offset logic as `_swap_team_starting_loadout()` so pre-placed and dynamically swapped factions always follow identical rules.

## 5. MEDIUM — Fix `AIBuildPlanner` Fallback Collision for `&"counter_foundry"`

### Root Cause
- In `scripts/systems/ai_build_planner.gd` (L39–42):
  - `&"barracks_t1"` matches `b.is_military_production and b.tech_tier == 1`.
  - `&"counter_foundry"` matches `b.is_military_production and b.tech_tier == 1 and b.batch_production_count <= 1`.
- For any future faction whose Tier-1 barracks does not use `GENESIS_V2`'s batch cloning (`batch_production_count == 1`), both roles silently resolve to the exact same building if `ai_build_profile` omits `&"counter_foundry"`.

### Required Changes
1. **`scripts/systems/ai_build_planner.gd` (`get_building_for_role()`):**
   - When resolving `&"counter_foundry"` via fallback, resolve `var primary_t1: BuildingData = get_building_for_role(&"barracks_t1")` first and skip `b == primary_t1` so the fallback picks a distinct second Tier-1 military structure (or returns `null` cleanly if the faction only has one Tier-1 production building).

## 6. MEDIUM — Eliminate `TechTreeOverlay` 0.5s Full-Tree Rebuild Jitter

### Root Cause
- `scripts/ui/tech_tree_overlay.gd` (L39–43) calls `_rebuild_tree()` every `0.5s`, which calls `queue_free()` on every child of `columns_row` and reconstructs all cards from scratch.
- With a `ScrollContainer` (Section 2) or hover tooltips, destroying and recreating the UI tree twice per second resets scroll position and flickers tooltips.

### Required Changes
1. **`scripts/ui/tech_tree_overlay.gd`:**
   - Store lightweight references to each rendered card's status badge label and panel `StyleBoxFlat` (keyed by `building_id`) during `_rebuild_tree()`.
   - Replace the `_process()` timer call to `_rebuild_tree()` with `_refresh_live_states()`, which only updates `[OWNED]` / `[READY]` / `[LOCKED]` status text and border tint in place without freeing or recreating controls.
   - Keep full `_rebuild_tree()` calls only in `_ready()` and when clicking a faction tab.
